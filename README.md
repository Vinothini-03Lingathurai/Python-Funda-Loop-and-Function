Python Assignment: While Loop, For Loop and Functions

📌 Project Overview

This project contains three Python programs developed as part of Python Fundamentals Assignment 3. The assignment focuses on understanding loops, control statements, and user-defined functions in Python.

The programs demonstrate how to implement a number guessing game, generate a multiplication table, and calculate Body Mass Index (BMI).

🎯 Objectives

Understand the use of while and for loops.

Practice control statements such as break, continue, and else.

Learn how to define and call functions.

Understand function parameters and return values.

Handle invalid user input using try-except.

Develop logical thinking and problem-solving skills.

📝 Programs Included

1. Number Guessing Game

File: number_guessing_game.py

Description:

A simple interactive game in which the computer generates a random number between 1 and 10, and the user attempts to guess it within three valid attempts.

Concepts Used:

-while loop

-if, elif, and else

-break to exit the loop when the guess is correct

-continue to skip invalid guesses

-try-except for input validation

-random.randint() to generate a random number

2. Multiplication Table Generator

File: multiplication_table.py

Description:

This program asks the user to enter a number and generates its multiplication table from 1 to 10 using a for loop.

Concepts Used:

-for loop

-range() function

-User input using input()

-Type conversion using int()

-Arithmetic operations

-Formatted output using f-strings

3. BMI Calculator

File: bmi_calculator.py

Description:

This program calculates Body Mass Index (BMI) using the user's weight in kilograms and height in meters.

Formula:

BMI = Weight (kg) / Height (m)²

Concepts Used:

-User-defined functions

-Function parameters

-return statement

-Floating-point numbers using float()

-Arithmetic operations

-Input validation and exception handling

-Formatted output using :.2f

🚀 Conclusion

This assignment strengthened my understanding of Python fundamentals through practical exercises. The three programs demonstrate the application of loops, control statements, functions, and input validation in solving basic programming problems.
